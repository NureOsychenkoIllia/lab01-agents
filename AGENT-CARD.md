## 2. Призначення

- **Предметна область:** методи HTTP (варіант 8 лабораторної роботи). Середовище містить сім
  перевірених об'єктів: GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS.
- **Зв'язок із кваліфікаційною роботою:** контракт RESTful API проєкту «SmartLease»
  (веб-орієнтована платформа автоматизації орендних відносин) та його інтеграційні тести.
- **Що робить агент:** відповідає на питання про методи HTTP лише за фактами, які повертає
  середовище: призначення методу, безпечність, ідемпотентність, порівняння методів. Якщо
  перевірених даних немає, агент прямо про це повідомляє.
- **Типові запити:**
  1. «Що робить метод PATCH?»
  2. «Порівняй GET і HEAD»
  3. «Чи ідемпотентний PUT?»
- **Чого агент не робить:** не вигадує фактів про методи, яких немає в середовищі; не виконує
  дій, для яких немає інструментів; не працює з персональними даними, секретами й мережею.

## 3. Архітектура

| Дія | Аргументи | Детермінована? | Змінює середовище? |
|---|---|---|---|
| `lookup_http_method` | `name` — ідентифікатор методу | так | ні |
| `check_property` | `method`, `property` (`safe` / `idempotent`) | так | ні |
| `finish` | `answer` — фінальна відповідь | — | ні |

- **Умови зупинки:** `finish` від моделі; `MAX_STEPS = 6`; `MAX_ACTIONS = 6`;
  `MAX_LLM_CALLS = 8`; критична помилка виклику моделі (`llm_error`).
- **Обробка відмов:** невідома дія або хибні аргументи — білий список валідатора, текст помилки
  стає спостереженням; відсутній об'єкт — маркер NOT_FOUND і заборона вигадувати; повторюваний
  пошук — ліміти кроків і дій; перевищення квоти — повторні спроби на транспортному рівні й
  вибір моделі з вищими лімітами.

## 5. Запуск

```sh
# власний агент
cd manual-agent && uv run python main.py "Порівняй POST, PUT і PATCH"

# ADK-агент
cd adk-agent && agents-cli playground
cd adk-agent && agents-cli run "Чи ідемпотентний PATCH?"
```

Змінні оточення: `GEMINI_API_KEY` (значення не наводиться), `GEMINI_MODEL`; для локальної
моделі — `ADK_LLM_BACKEND`, `LOCAL_MODEL`, `LOCAL_API_BASE`.

## 6. Результати експерименту

- **Середня кількість викликів LLM:** one-shot 1,0 / власний 2,6 / ADK 1,8 (локальна 1,8).
- **Середній час, с:** one-shot 10,71 / власний 4,81 / ADK 1,85 (локальна 5,24).

## 7. Відомі обмеження та ризики

- У середовищі сім методів, тому TRACE, CONNECT і розширення на кшталт PROPFIND не підтримуються.
- Модель може обрати зайвий пошук на загальне питання (запит типу E у власному агенті).
- Локальна модель не відокремлює міркування від відповіді й іноді не завершує текст.
- Вільний рівень Gemini API обмежує кількість запитів на добу; дані вільного рівня Google може
  використовувати для покращення продуктів, тому в роботі лише відкриті навчальні дані.
